# Принципы Норы Галь для Amendeor

Источник: Нора Галь, «Слово живое и мёртвое», издание 2001 года, [PDF пользователя](https://dramafond.ru/wp-content/uploads/2014/12/Nora_Gal_Slovo_zhivoe_i_mertvoe.pdf), 147 страниц. Локальная копия: `.reference/Nora_Gal_Slovo_zhivoe_i_mertvoe.pdf` (вне Git), SHA-256 `76ead4760dc819a7ec18ad996b44c53397d8ee62bbd01bf1a5aab6c034bb3952`. Номера страниц ниже соответствуют PDF. Формулировки принципов — наша редакторская интерпретация, не цитаты и не полный пересказ книги.

Это отбор для русской художественной прозы. Галь обсуждает также перевод, научно-популярный и детский текст; специальные принципы помечены. Каждый пункт — повод проверить фразу **в контексте**. Ни один стилевой сигнал сам по себе не доказывает ошибку и не разрешает автоматическую замену.

Обозначения: **С** — можно найти узким текстовым сигналом; **К** — нужна оценка смысла и контекста; **П** — относится только к переводу при доступном оригинале. Все находки остаются рекомендациями редактору.

## Как применять в Amendeor

1. **Детерминированный слой** ищет только узкие признаки и показывает точную цитату: канцелярские связки, пустые глаголы с названием действия, избыток абстрактных существительных и плотные причастные конструкции. Срабатывание — `hint`, не ошибка.
2. **Контекстный слой** получает абзац, сцену, сведения о говорящем и жанре. Он объясняет конкретный риск: двусмысленность, сбой образа, не тот голос, нарушенную хронологию. Если причина не доказана текстом, возвращает `NO_FINDING`.
3. **Проверка сохранности** для всякой предложенной правки сравнивает значение, степень уверенности, факты, персонажа, интонацию и художественный приём. Для перевода требуется оригинал; без него пункты `П` не запускать.
4. **Исключения**: протокол, документ, судебная речь, прямая речь сухого персонажа, намеренная стилизация, цитата, технический термин, осмысленный повтор. Не подавлять находку автоматически, если стиль документа является предметом редактирования; указывать контекст в выводе.
5. **Приоритет**: сначала объективная ошибка или непонятный смысл, затем неудачный регистр, затем вкусовое предложение. Последние два уровня никогда не принимаются автоматически.

Книга — сборник редакторских разборов, а не формальный стандарт. Некоторые оценки заимствований и разговорности зависят от эпохи издания; Amendeor должен проверять уместность слова в современном тексте, а не автоматически заменять его по списку из книги.
