# Проверка «Нора Галь» — пилот

Это отдельная диагностическая проверка русской прозы, вдохновлённая темой канцелярита в книге Норы Галь «Слово живое и мёртвое». Она не воспроизводит книгу и не претендует на полный набор авторских правил. Источники для выбора темы: [издательство АСТ](https://ast.ru/book/slovo-zhivoe-i-mertvoe-891044/) и [издательство Эксмо](https://eksmo.ru/book/slovo-zhivoe-i-mertvoe-ITD1396660/). Конкретные регулярные выражения ниже — наше прикладное приближение, а не цитаты из книги.

Запуск:

```sh
node src/cli.ts check path/to/book --guide nora-gal
node src/cli.ts check path/to/book --guide nora-gal --json
```

Пилот отмечает три узких сигнала:

| ID | Что ищет | Вопрос при проверке |
| --- | --- | --- |
| `office.action-noun` | `осуществлять/производить` + название действия | Можно ли назвать действие простым глаголом без потери точности? |
| `office.purpose-frame` | `в целях` + абстрактное действие | Нужна ли формальная рамка цели? |
| `office.empty-existence` | `имеет место` и близкие формы | Можно ли назвать событие прямо? |

Результат содержит место, точную цитату, причину и версию набора. Прямая речь пропускается. Найденное место — повод перечитать фразу, а не ошибка и не предложение автоматической замены. Официальный документ, протокол или намеренно сухой голос рассказчика могут требовать именно такой речи. Команда не создаёт run, не меняет `manuscript/` или `edited/` и не участвует в `accept`.

Чтобы расширить проверку по конкретным положениям книги, нужен экземпляр текста, предоставленный пользователем, и отдельный разбор принципов, примеров и исключений.
